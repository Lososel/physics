# Откройте Мир Физики

Плакат А4 для кабинета физики с QR-кодом, сделанный по образцу плаката по математике.

- `index.html`: сам плакат. Откройте его в браузере и нажмите «Печать (A4)». Поля 0, включите «Фоновая графика».
- `learn.html`: страница, которая открывается по QR-коду: видеоуроки, интересные факты, задания и интерактивы.

QR-код ведёт на `https://lososel.github.io/physics/learn.html`. Он заработает, когда для репозитория включён GitHub Pages:
**Settings → Pages → Deploy from a branch →** выберите ветку и папку `/ (root)`.
